This is a website to display potential blazar flare lightcurves from AGN sources. The purpose of this Repo is to gather feedback to repeatedly improve this site, in order to prepare for the upcoming NASA mission COSI.

## Feedback
If you have any suggestions, would like for things to be clarified on the website itself, find a bug, etc, please use the Issues category to open an issue. I will try to respond to every query, but it may take some time.

## Signing up for E-Mail Alert list
If you would like to receive regular e-mail alerts about potential flaring sources and agree to send feedback regarding this project, please contact me via Slack or e-mail to be added to the e-mailing list.
